Create Time Lines Plot

This notebook will create a timeline plot showing the use of the 3 CDK4/6 inhibitors over time, with key timeline events highlighted.

# load some required packages for data carpentry and visualisation
require(dplyr)
require(tidyr)

# Get the dataset 
# Requires cleaned data
cdk46Data <- readRDS(here::here("data/cdk46_op_hosp_clean.RDS"))

# agregate the data to VTM & month (i.e. no trust level data needed or formulation)
cdk46Data |>
  # get the VTM (ingredient)
  separate_wider_delim(vmp_name, delim=" ", names = c("VTM", "strength", "form")) |>
  # summarise the data using month and VTM
  group_by(year_month, VTM) |>
  summarise(ddd=sum(ddd_quantity)) -> cdk46MonthlyData
`summarise()` has grouped output by 'year_month'. You can override using the `.groups` argument.
head(cdk46MonthlyData)

Create an initial verson of the graph

require(ggplot2)

cdk46MonthlyData |>
  ggplot(aes(
         x=year_month,
         y=ddd,
         colour = VTM
       )) +
  geom_line(lwd=1.1) +
  theme_classic()

Create a smoother version

The data is quite spikey and might be better shown as a moving average over 3 months

require(zoo) # for rolling averages...

cdk46MonthlyData |>
  #filter(VTM == "Palbociclib") |>
  ungroup() |>
  group_by(VTM) |>
  mutate(moving_av = rollmean(ddd, k = 3, fill = ddd, align = "right")) |>
  ggplot(aes(
         x=year_month,
         y=moving_av,
         colour = VTM
       )) +
  geom_line(lwd=1.1) +
  theme_classic()

This uses right moving average and results in the first 3 data points being lower than they should perhaps be. It doesn’t do much to smooth out the Palbociclib spike.

Format the Graph

cdk46MonthlyData |>
  ggplot(aes(
         x=year_month,
         y=ddd,
         colour = VTM
       )) +
  geom_line(lwd=1.1) +
  theme_classic() -> cdk46Plot

cdk46Plot +
  # Title the plot and add a caption with DDD
  labs(title = "Trends in CDK4/6 inhibitor prescribing in England",
         subtitle = "Issue of defined daily doses from hospital pharmacies per month",
         caption = "Defined daily dose: Abemaciclib 300mg, Palbociclib 94mg, Ribociclib 450mg") +
  
  # Explain missing data
  geom_label( aes(x = as.Date("2018-07-01"), 
                 y = 50000, 
                 label = "Data prior to\n2019 is\nnot available"), 
            hjust = 0.5, vjust = 1, size = 3, inherit.aes = F
            ) +
  # Force x axis to show wider timeline
  xlim(c(as.Date("2017-07-01"), as.Date("2024-12-31"))) +
  
  # Format the y-axis scales and set a better range
    # Tidy up the y-axis
  scale_y_continuous("Monthly defined daily doses",
                     labels = scales::label_comma(), # Add commas to numbers
                     limits = c(0, 200000), 
                     breaks = seq(0, 200000, by = 50000))+
  
  # Label x-axis
  xlab("Month")  -> cdk46Plot
